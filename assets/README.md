# Homepage media

`tesla-exhibit.jpg` is a still extracted at 00:01:44 from the project's existing
`tesla-demo-fast.mp4` recording in the creator's `sota-professor-progress` folder.
It was scaled to 1600 × 900 and encoded as JPEG (about 108 KiB); the original
recording is unchanged. It shows a Nikola Tesla AI portrayal and the AR prototype.
The recording's physical room background remains visible in this actual prototype
capture. The creator reviewed the redesign with this image and authorized its
publication to the existing project website.

The frame is from accelerated footage. A still makes no real-time preparation or
interaction-speed claim. The homepage labels the AI portrayal and actual capture,
and explicitly identifies the linked YouTube video as a separate Quest 3 recording.
